# ForkRight visual system

Source asset: `public/forkright-logo.png` (1254 × 1254).

## Extracted visual language

- Near-black navy field: `#001522` to `#031e2b`, with soft cyan bloom.
- Primary signal gradient: electric cyan `#19e7f2` → mint `#42f4b6`.
- Motif: a protected community at the crown of a branching succession tree.
- Geometry: heavy rounded square, monoline branches, circular terminals, shield/hexagon.
- Mood: infrastructural, protective, continuous—not financial or speculative.

## Interface translation

- Dark archival interface on warm mist `#e8f2ee`, not a generic all-black dashboard.
- Editorial serif headlines paired with compact mono metadata.
- Borders are thin and structural; rounded corners are reserved for identity marks and pills.
- Cyan–mint is used only for active state, lineage, and verified continuity.
- The central timeline branches visually from `HEALTHY` to restoration or succession.
- Motion is restrained: staged reveal, status pulse, line growth, and hover elevation.

## Accessibility

- Body text contrast ≥ 4.5:1.
- State never depends on color alone; every state includes a label and icon.
- Focus outlines use the high-contrast cyan signal.
- Reduced-motion users receive static transitions.
